# Pre-publication checklist

- [ ] Verify that the included source is only a **commented historical SQL archive** and newly authored example SQL.
- [ ] Review every committed file for usernames, password values, tokens, Snowflake locators, query IDs, private/company material, and customer personal data.
- [ ] Confirm the original Kaggle/sample CSV was **not** committed; obtain explicit rights before adding any third-party dataset.
- [ ] Verify no `.env`, secret files, account exports or screenshots are tracked in the initial Git commit.
- [ ] Ensure the README truthfully describes manual and separate learning exercises, not a fully automated production system.
- [ ] Publish first as **Private**, verify the GitHub file list, then change to **Public** after reviewing the changes and git history.
- [ ] View the public README in an incognito window before adding the repository to your resume.
