# Dataset note

This repository intentionally does **not** include the source retail CSV because the originally shared Sales archive contains SQL only, not the dataset or its license. The source was previously described as a Kaggle retail sales sample with 25 columns (often called `sales_data_sample.csv`), but no verified canonical dataset URL is supplied here.

Obtain an appropriately licensed copy from the original publisher, verify the header/schema, and upload it into your own Snowflake test stage. Do not commit customer names, addresses, contact details or phone numbers from real/third-party data.
